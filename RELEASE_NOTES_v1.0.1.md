# v1.0.1 release notes

## Purpose

This patch release contains the same frozen computational materials as
`v1.0.0`. It updates the citation metadata with the formal author name and
affiliation and triggers the Zenodo archive after GitHub-Zenodo integration was
enabled.

No raw STATS19 or CAS data, fitted model binaries, record-level predictions,
analysis rules, or scientific results were changed.

## Version boundary

- Primary journal target: IEEE Access.
- The `v1.0.0` tag remains immutable and continues to identify the original
  frozen computational boundary.
- This release corrects only repository-level author and citation metadata.
- Zenodo should archive this release as the citable software supplement.

## Data boundary

Raw data and record-level outputs remain excluded from the repository. Source
URLs, retrieval dates, checksums, and attribution requirements remain in the
repository documentation.
